0前言：為什麼用本地模型學三角函數

傳統學習三角函數常需要反覆查閱教科書或上網搜尋公式推導，但網路資訊品質參差不齊，且涉及隱私與網路依賴。本教材示範如何完全在 本機端 建置 AI 學習環境，讓你隨時離線地請本地語言模型協助：

  • 解釋 sin、cos、tan 在單位圓上的幾何意義
  • 逐步推導 和角公式、差角公式、雙角公式、半角公式
  • 檢查推導過程是否正確、提供應用範例與練習題

第一模型：Gemma 3 26B

Google Gemma 家族的大型指令調校模型，適合較複雜的數學推理與多語言（含繁體中文）對話。若 LM Studio 模型庫中顯示為 Gemma 3 27B，安裝與設定步驟完全相同，只需更換模型名稱。

GemmaGGUF

第二模型：Qwen 3

阿里雲 Qwen 3 系列（建議從 4B 或 8B 開始），中文理解能力極強，佔用資源較少，是筆記型電腦先跑通環境的首選。

Qwen 3GGUF
運作方式：LM Studio 負責在本機執行模型並提供 http://127.0.0.1:1234/v1 本地端點；OpenCode 則透過該端點與模型對話。整個過程不需要雲端 API Key，對話內容也不會離開你的電腦。

4啟動 LM Studio 本地伺服器（OpenAI 相容 API）

OpenCode 需要一個 API 端點才能與模型對話。LM Studio 的「本地伺服器」(Local Server) 功能會把本機模型偽裝成 OpenAI API，讓 OpenCode 可以連接。

  1. 在 LM Studio 左側選單點擊 Local Server。
  2. 在「模型」下拉選單中，選擇剛下載的模型（例如 gemma-3-26b-it 或 qwen3-4b）。
  3. 設定 GPU 卸載層數（GPU Offload）：顯示記憶體充足可設為全卸載；若記憶體不足，降低層數或改為 CPU 推理（會較慢）。
  4. 點擊 Start Server。伺服器啟動後，預設端點為：
http://127.0.0.1:1234/v1
LM Studio 不需要真正的 API Key，但某些工具會要求填寫，此時填入任意字串（例如 lm-studio 或 1234）即可。

5安裝 OpenCode

OpenCode 是終端機 AI 助手，可直接呼叫本地 LM Studio API。安裝步驟如下：

  1. 安裝 Node.js（官網：nodejs.org），確認版本：
node -v
npm -v
  1. 以 npm 全域安裝 OpenCode：
npm install -g opencode
  1. 確認安裝成功：
opencode --version
如果你沒有 npm 權限，Windows 建議以系統管理員身分開啟 PowerShell；macOS/Linux 可視需求加上 sudo，或使用 Node 版本管理工具（nvm / fnm）避免權限問題。

8三角函數基礎：單位圓與弧度制

在推導角公式之前，先建立三角函數的幾何直覺。所有推導都以 單位圓（半徑 r = 1 的圓）為基礎。

sin²θ + cos²θ = 1
勾股定理在單位圓上的直接結果，也是所有角公式推導的基礎。

9角公式推導：和角、差角、雙角、半角

本節使用 旋轉行列式 與 單位圓幾何 兩種方式推導，並示範如何請本地模型協助檢查每一步。

9.1 和角公式

sin(α + β) = sin α·cos β + cos α·sin β
cos(α + β) = cos α·cos β − sin α·sin β
tan(α + β) = (tan α + tan β) / (1 − tan α·tan β)
推導關鍵：利用單位圓上兩點的餘弦定理，或複數旋轉 e^{i(α+β)} = e^{iα}·e^{iβ}。

9.2 差角公式

sin(α − β) = sin α·cos β − cos α·sin β
cos(α − β) = cos α·cos β + sin α·sin β
將 β 替換為 −β，並使用 sin(−β) = −sin β、cos(−β) = cos β 即可從和角公式推出。

9.3 雙角公式

sin(2α) = 2·sin α·cos α
cos(2α) = cos²α − sin²α = 2cos²α − 1 = 1 − 2sin²α
tan(2α) = 2·tan α / (1 − tan²α)
令 β = α 代入和角公式即可得到。

9.4 半角公式

sin²(α/2) = (1 − cos α) / 2
cos²(α/2) = (1 + cos α) / 2
由 cos(2·(α/2)) = cos α 並代入雙角公式，移項兩邊除以 2 得到。

9.5 和差化積 / 積和化差

類別公式
和差化積sin A·cos B = [sin(A+B) + sin(A−B)] / 2
cos A·cos B = [cos(A+B) + cos(A−B)] / 2
sin A·sin B = [cos(A−B) − cos(A+B)] / 2
積和化差sin A + sin B = 2·sin((A+B)/2)·cos((A−B)/2)
cos A + cos B = 2·cos((A+B)/2)·cos((A−B)/2)

10用本地模型協助推導公式（提示詞範例）

環境跑通後，你可以直接在 OpenCode 中輸入下列提示詞，請 Gemma 3 26B 或 Qwen 3 協助推導與解釋。全部對話在本機完成，不會上傳雲端。

建議提示詞 A：完整推導（適合 Gemma 3 26B）

請用繁體中文，以高中數學程度，逐步推導下列三角函數角公式，
每一步都請說明使用的公式或定理：

1. 和角公式：sin(A+B)、cos(A+B)、tan(A+B)
2. 差角公式：sin(A−B)、cos(A−B)
3. 雙角公式：sin(2A)、cos(2A)、tan(2A)
4. 半角公式：sin²(A/2)、cos²(A/2)

請盡量使用單位圓與幾何說明的文字描述，並列出代入數值的計算範例。

建議提示詞 B：快速驗證（適合 Qwen 3）

請用繁體中文快速驗證以下推導是否正確，若有錯誤請指出並修正：

已知 sin(A+B) = sin A cos B + cos A sin B，
請推導出 sin(2A) = 2 sin A cos A，
並說明每一步的代入來源。

在 OpenCode 中的操作流程

  1. 確認 LM Studio 已載入模型並啟動 Local Server。
  2. 在終端機執行 opencode，選擇或切換至目標模型（Gemma 3 26B 或 Qwen 3）。
  3. 複製上方提示詞貼上並送出。
  4. 閱讀模型回應，若發現推導跳步，可續問：「請補充第 3 步的詳細代入過程」。
本地模型偶爾會出現計算錯誤或公式誤植，建議將模型給出的推導與本教材附錄的速查表對照，重要公式請自行再驗證一次。
